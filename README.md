# Quiz Computacional

Aplicação educacional estática para praticar conhecimentos básicos de Computação com questões de
múltipla escolha.

## Execução local

Sirva esta pasta como arquivos estáticos locais e abra `index.html` no navegador. Evite abrir o
arquivo diretamente com `file://`, pois o navegador pode bloquear o carregamento das questões em
JSON.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
